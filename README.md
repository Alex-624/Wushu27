# Overview

This project was made by IMT Atlantique students for the Wushu Brest association, to visualize motion-tracked kung-fu movements in a realistic 3D environment.

# Setup

- Select a folder and open it on your command terminal.
- Use the command `git clone https://github.com/Alex-624/Wushu27.git`
- Open Unity Hub
- In the tab "Projects", click "Add" > "Add project from disk"
- Select the Wushu27 folder
- Your project is now ready to work
